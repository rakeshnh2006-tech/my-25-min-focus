1. Executive Summary & Product Objective

FocusFlow is an enterprise-grade, student-centered Pomodoro study and time-management platform designed to optimize deep focus, eliminate distraction, and cultivate sustainable academic habits. Built on TypeScript across the entire stack, the platform incorporates evidence-based productivity techniques—specifically the 25-minute Pomodoro method with structured 5-minute short breaks and 15-minute long breaks after every four-session cycle.

Core Engineering Objectives

  • Zero-Drift Timer Architecture: Traditional browser setInterval timers suffer from severe timing drift when backgrounded or throttled by operating system energy savers. FocusFlow overcomes this with target-timestamp reconciliation and server-synchronized session state.
  • Procedural Audio Feedback: Eliminates heavyweight external audio assets by utilizing the browser's native Web Audio API to procedurally generate soothing sine and triangle wave multi-tone chimes upon session completion.
  • Relational Study Mapping: Unlike generic Pomodoro apps, sessions are strongly coupled to student academic subjects and study tasks, allowing granular analytics on time allocation, completed session counts, and progress tracking.
  • Resilient Daily Streak Mechanics: Timezone-aware streak computation that gracefully handles study sessions spanning midnight, rest days, and varying UTC offsets.
  • Dual Deployment Topology: Architected to run as both a unified long-running Express server and as serverless functions on Vercel backed by managed PostgreSQL (e.g., Supabase or Neon).

3.2 Authentication & Session Flow

  1. User navigates to /login and clicks Sign in with Google.
  2. Browser initiates GET request to /api/auth/google.
  3. Passport directs user to Google's OAuth 2.0 consent dialog requesting profile and email scopes.
  4. Google redirects user back to /api/auth/google/callback with an authorization code.
  5. Express exchanges code for tokens, retrieves Google profile, queries the Prisma User model, creating the account and default preferences in a database transaction if first-time.
  6. Passport serializes the User ID into PostgreSQL via connect-pg-simple and sets an encrypted focusflow.sid cookie with httpOnly: true, sameSite: 'lax', and secure: true.
  7. User is redirected to the dashboard (/ or /#dashboard).

Zero-Drift Timer Calculation Engine

When a focus session starts, rather than simply decrementing an integer every 1000ms, the engine computes:

Drift-Free Formulation:
targetEndTimestamp = Date.now() + (plannedSeconds * 1000);
secondsRemaining = Math.max(0, Math.round((targetEndTimestamp - Date.now()) / 1000));

This guarantees that if the student switches tabs, locks their laptop, or puts the browser into power-saving mode, waking the machine instantly calculates the precise elapsed time without loss of session integrity.

Web Audio API Procedural Synthesizer

FocusFlow does not rely on MP3 files or CDN assets. Instead, soundManager initializes an AudioContext and programmatically constructs musical chords using sine and triangle oscillator nodes:

  • Focus Session Complete Chime: Synthesizes a four-note major arpeggio [C5 (523.25 Hz), E5 (659.25 Hz), G5 (783.99 Hz), C6 (1046.50 Hz)] staggered by 120ms with exponential gain decay.
  • Break Complete Chime: Uplifting two-tone major third [E5 (659.25 Hz), A5 (880.00 Hz)] signalling it is time to resume deep study.
  • Subtle Click: Micro-tick (800 Hz sine burst for 30ms) for timer interactions.

5. Backend Server Architecture, Middleware & Services

Express Middleware Pipeline

  1. Helmet: Sets strict HTTP security headers with cross-origin policies configured for API asset delivery.
  2. CORS: Enforces whitelist filtering allowing local development (localhost:3000) and production domain (my-25-min-focus.vercel.app) with credentials: true.
  3. Rate Limiting: Enforces dual limiters—a general API limiter (1000 requests/15m) and a sensitive Auth limiter (100 attempts/15m).
  4. Session Storage (connect-pg-simple): Persists session states in PostgreSQL table sessions, utilizing custom Supabase CA certificates to resolve SSL connection validation in serverless runtimes.
  5. Passport: Authenticates sessions and injects user profile into req.user.
  6. Route Handlers & Zod Validation: Validates payloads before dispatching to business controllers.
  7. Central Error Handler: Catches uncaught rejections and standardizes errors into JSON responses with proper HTTP status codes.

Streak & Activity Algorithm

The StreakService processes all user completed sessions in their localized timezone:

  • Extracts unique study dates formatted as YYYY-MM-DD using Intl.DateTimeFormat with the user's configured timezone.
  • Calculates continuous consecutive calendar days.
  • Gracefully maintains active streaks if the student studied yesterday but has not yet completed their session for today.

  /**
   * Parses JSON string of pause intervals
   */
  static parsePauseIntervals(pauseStr: string | null | undefined): PauseRecord[] {
    if (!pauseStr) return [];
    try {
      const parsed = JSON.parse(pauseStr);
      return Array.isArray(parsed) ? parsed : [];
    } catch {
      return [];
    }
  }

  /**
   * Calculates total paused time in seconds from pause records up to a reference time
   */
  static calculateTotalPausedSeconds(
    pauses: PauseRecord[],
    referenceTime: Date = new Date()
  ): number {
    let totalSeconds = 0;
    const refMs = referenceTime.getTime();

    for (const pause of pauses) {
      const startMs = new Date(pause.start).getTime();
      const endMs = pause.end ? new Date(pause.end).getTime() : refMs;
      if (endMs > startMs) {
        totalSeconds += Math.floor((endMs - startMs) / 1000);
      }
    }

    return Math.max(0, totalSeconds);
  }

  /**
   * Calculates actual focused seconds between startedAt and endedAt (or now),
   * subtracting all paused intervals.
   */
  static calculateActualDuration(
    startedAt: Date,
    endedAt: Date = new Date(),
    pauses: PauseRecord[]
  ): number {
    const startMs = new Date(startedAt).getTime();
    const endMs = new Date(endedAt).getTime();
    const totalElapsedSeconds = Math.max(0, Math.floor((endMs - startMs) / 1000));
    const totalPausedSeconds = this.calculateTotalPausedSeconds(pauses, endedAt);
    return Math.max(0, totalElapsedSeconds - totalPausedSeconds);
  }

  /**
   * Computes the new target end timestamp when resuming a paused session
   */
  static calculateNewTargetEnd(
    originalTargetEnd: Date,
    pauseStart: Date,
    resumeTime: Date = new Date()
  ): Date {
    const pauseDurationMs = Math.max(0, resumeTime.getTime() - new Date(pauseStart).getTime());
    return new Date(new Date(originalTargetEnd).getTime() + pauseDurationMs);
  }

  /**
   * Checks if a session status transition is allowed
   */
  static isValidTransition(
    currentStatus: string,
    action: 'PAUSE' | 'RESUME' | 'COMPLETE' | 'ABANDON' | 'SKIP'
  ): boolean {
    switch (action) {
      case 'PAUSE':
        return currentStatus === 'RUNNING';
      case 'RESUME':
        return currentStatus === 'PAUSED';
      case 'COMPLETE':
        return currentStatus === 'RUNNING' || currentStatus === 'PAUSED';
      case 'ABANDON':

      case 'SKIP':
        return currentStatus === 'RUNNING' || currentStatus === 'PAUSED';
      default:
        return false;
    }

export class StreakService {
  /**
   * Formats a date into YYYY-MM-DD string in a specified timezone (defaults to UTC)
   */
  static formatDateKey(date: Date, timezone: string = 'UTC'): string {
    try {
      return new Intl.DateTimeFormat('en-CA', {
        timeZone: timezone,
        year: 'numeric',
        month: '2-digit',
        day: '2-digit',
      }).format(date);
    } catch {
      return date.toISOString().split('T')[0];
    }
  }

  /**
   * Calculates current streak and longest streak from completed focus session dates
   */
  static calculateStreaks(
    sessionDates: Date[],
    timezone: string = 'UTC',
    referenceDate: Date = new Date()
  ): { currentStreak: number; longestStreak: number; totalActiveDays: number } {
    if (!sessionDates || sessionDates.length === 0) {
      return { currentStreak: 0, longestStreak: 0, totalActiveDays: 0 };
    }

    // Extract unique sorted dates as YYYY-MM-DD
    const uniqueDateSet = new Set<string>();
    for (const d of sessionDates) {
      uniqueDateSet.add(this.formatDateKey(new Date(d), timezone));
    }

    const uniqueDates = Array.from(uniqueDateSet).sort();
    const totalActiveDays = uniqueDates.length;

    if (totalActiveDays === 0) {
      return { currentStreak: 0, longestStreak: 0, totalActiveDays: 0 };
    }

    // Calculate longest streak
    let longestStreak = 1;
    let currentRun = 1;

    for (let i = 1; i < uniqueDates.length; i++) {
      const prevDate = new Date(uniqueDates[i - 1] + 'T00:00:00Z');
      const currDate = new Date(uniqueDates[i] + 'T00:00:00Z');
      const diffDays = Math.round((currDate.getTime() - prevDate.getTime()) / (1000 * 60 * 60 * 24));

      if (diffDays === 1) {
        currentRun += 1;
        if (currentRun > longestStreak) {
          longestStreak = currentRun;
        }
      } else if (diffDays > 1) {
        currentRun = 1;
      }
    }

    // Calculate current streak relative to referenceDate
    const todayStr = this.formatDateKey(referenceDate, timezone);
    const yesterday = new Date(referenceDate);
    yesterday.setUTCDate(yesterday.getUTCDate() - 1);
    const yesterdayStr = this.formatDateKey(yesterday, timezone);

    let currentStreak = 0;
    const hasToday = uniqueDateSet.has(todayStr);
    const hasYesterday = uniqueDateSet.has(yesterdayStr);

    if (hasToday || hasYesterday) {
      let checkDate = new Date(referenceDate);
      if (!hasToday) {
        // Did not study today yet, but streak is active from yesterday
        checkDate = yesterday;
      }

      while (true) {
        const key = this.formatDateKey(checkDate, timezone);
        if (uniqueDateSet.has(key)) {
          currentStreak += 1;
          checkDate.setUTCDate(checkDate.getUTCDate() - 1);
        } else {
          break;
        }
      }
    }

    return {
      currentStreak,
      longestStreak: Math.max(longestStreak, currentStreak),
      totalActiveDays,
    };
  }

export async function apiRequest<T = any>(
  endpoint: string,
  options: RequestInit = {}
): Promise<T> {
  const url = endpoint.startsWith('http') ? endpoint : endpoint;

  const defaultHeaders: Record<string, string> = {
    'Content-Type': 'application/json',
  };

  const response = await fetch(url, {
    ...options,
    credentials: 'include', // Ensure cookies are sent with every cross-origin/proxied request
    headers: {
      ...defaultHeaders,
      ...options.headers,
    },
  });

  // Handle empty body responses (e.g. 204)
  if (response.status === 204) {
    return {} as T;
  }

  let data: any;
  const contentType = response.headers.get('content-type');
  if (contentType && contentType.includes('application/json')) {
    data = await response.json();
  } else {
    data = { message: await response.text() };
  }

  if (!response.ok) {
    throw new ApiError(
      data.message || data.error || `Request failed with status ${response.status}`,
      response.status,
      data.details
    );
  }

  return data as T;
}
